# MirrorAI Documentation Registry

This directory is the official documentation registry for MirrorAI.

## Governance order

1. `constitution/MIRROR-CONST-001.md` — MirrorAI Constitution
2. `prd/MIRROR-PRD-001.md` — Product Requirements Document
3. `risk/MIRROR-RISK-001.md` — Risk Engine Specification
4. `architecture/MIRROR-ARCH-001.md` — Technical Architecture
5. `audit/MIRROR-AUDIT-001.md` — Prototype Audit Report
6. `decisions/MIRROR-ADR-001.md` — Technology Stack Decision

## Documentation principle

Higher-level documents govern lower-level implementation decisions. GitHub Issues translate approved requirements and architecture into executable work.

When a significant architecture decision changes, create or update an Architecture Decision Record rather than relying only on chat history or code comments.
